Wizard kalibrasi PX4

Gyro, akselerometer enam sisi, kompas dan level. Status ID sensor bukan bukti kualitas kalibrasi.

Kontrol: nonaktif
Sebelum mengkalibrasi: kendaraan harus disarmed, roda/aktuator terisolasi secara fisik, Cube stabil, USB terkoneksi, dan hanya satu aplikasi memegang port serial. Proses sensor tertentu memerlukan gerakan manual sesuai instruksi. Jangan lakukan kalibrasi ESC/motor dari halaman ini.

Status progres/ACK kalibrasi

Belum ada tindakan

Jika PX4 mengirim STATUSTEXT progress, lihat tab Pre-arm & log. Status ACK diterima bukan otomatis berarti kalibrasi selesai.

Parameter konfigurasi PX4

Parameter dibaca langsung dari pengendali lewat MAVLink, tidak ditulis oleh web.

Nilai “belum didapat” dapat berarti belum selesai dibaca, firmware tidak mendukung parameter, atau response timeout. Jangan menebak nilainya.

Uji pra-arm tanpa menyalakan motor

Minta PX4 menjalankan ulang pre-arm checks menggunakan MAV_CMD_RUN_PREARM_CHECKS (401). Tidak meminta ARM (400).

Respons ACCEPTED berarti pemeriksaan diminta, bukan berarti kendaraan aman/siap ARM.

Belum diuji

Urutan persiapan tanpa RC

01
Tetapkan airframe rover resmi yang cocok pada PX4 (SYS_AUTOSTART belum terisi).
02
Sesuaikan COM_RC_IN_MODE: 1 untuk joystick MAVLink atau 4 tanpa manual input. Jangan nonaktifkan failsafe data-link/E-stop.
03
Kalibrasikan gyro, accelerometer, compass dan level; verifikasi estimator serta sensor.
04
Untuk AUTO.MISSION, pastikan GPS/posisi global sehat dan misi valid. Tidak cukup hanya COM_ARM_WO_GPS=1.
05
Uji ARM nyata hanya pada bench terisolasi, setelah operator memastikan sistem keselamatan independen.
