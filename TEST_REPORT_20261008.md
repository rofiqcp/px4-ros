## Scope / limitations
This is a native C++ MAVLink ROS 2 backend, not a visual Mission Planner/GCS replacement. It provides live telemetry, IMU bank streams, calibrated highres IMU, EKF/odometry diagnostics, parameter read/write, mission upload/download, guarded target setpoints/mode, and raw MAVLink optional stream. A full desktop/map UI, full calibration wizard, firmware flashing, MAVFTP/ULog retrieval and flight testing require additional engineering. PX4 must first receive the appropriate airframe configuration, connected GPS or external localization, calibrated sensors and reviewed failsafes.
